# 两段式检测

在设置中选择「两段式检测」。先隐藏已知失效或地区不可达的线路；隐藏可恢复，整批检测只处理可见线路。程序不会凭一次失败自动隐藏线路。

第一段采用快检验证解码和直播推进，成功后进入连续精测；粗筛不直接发布。精测要求速率严格大于 100 KB/s、画面高度至少 720。已有检测方式和用户设置保持可选。

失败和未能验证冷却后最多复测一次，每次任务只计一次独立结果，最近保存三次达标记录。已达标线路允许一轮失败，连续两轮独立检测失败后停用。手动启停仍按原有约定在测速完成后恢复自动。

批量检测逐条执行，同上游有请求间隔。429 尊重 Retry-After 并指数退避；长时间冷却保留原结果和启停，之后另选时段手动复测，不自动无限重试。

运行 `python verify_pipeline.py` 验证阶段顺序、严格速率边界、未能验证冷却和独立历史计数。真实提升幅度需在原网络复核，云端仅使用模拟数据。
