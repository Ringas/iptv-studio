# 频谱 IPTV Studio v1.1.3

恢复频道库原有的 M3U 订阅入口，以一键复制替代跳转，便于把地址粘贴到电视或播放器。

## 更新内容

- 保留频道库标题右侧的“M3U 订阅”文字和蓝色圆角样式，跳转箭头替换为复制图标。
- 点击直接复制当前访问地址对应的 M3U 链接，不打开新页面；兼容域名、局域网 HTTP 和子路径部署。
- 兼容剪贴板不可用或权限被拒绝的情况，失败时提供替代复制方式，不误报成功。
- 保留键盘操作、辅助名称和明确的复制反馈；恢复原工具栏布局，移除中间设计的无用样式。
- 不引入新的运行依赖。ZIP 与 Docker 镜像继续通过白名单只包含运行组件及必要许可，排除本地配置、数据库、日志、研究和测试材料。

## 部署与升级

镜像：`talktoo/iptv-studio:v1.1.3`，同步更新 `latest`；平台为 **linux/amd64**。旧版本 Release 和版本镜像均保留。

使用仓库 Compose，执行 `docker compose pull` 和 `docker compose up -d`。升级前停止旧实例并备份数据目录，继续挂载原数据卷，不要同时启动两个实例访问同一数据库。默认上海时区，无需设置 TZ。

进入频道库，点击 **M3U 订阅**，将复制的地址粘贴到播放器。发行 ZIP 附固定版本 Compose 和 SHA256SUMS。

## 验证

推送前检查复制行为、脚本语法、演示构建及运行包内容。远端发布流程执行全部隔离回归和镜像启动、时区、日志、解码、非 root 进程及重启数据保留验证，通过后发布。发布完成后再运行一轮完整回归。

在线 Demo 仅含虚构数据，不连接真实直播源。此版不改变线路检测标准，不宣称检测速度或准确率提升。
