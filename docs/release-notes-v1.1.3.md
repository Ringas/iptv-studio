# 频谱 IPTV Studio v1.1.3

修复 v1.1.2 遗漏的界面时间显示不一致问题，保留 v1.1.2 及所有旧版本。

## 更新内容

- 速率详情不再直接显示带 T/Z 的原始时间；检测详情、频道详情、订阅最近更新、下次更新时间和节目单共用时间格式 `YYYY-MM-DD HH:mm:ss.SSS`。
- 界面跟随服务端运行时区，默认上海；不再由访问设备的语言或时区决定显示格式。调整 TZ 后界面和后台保持一致。
- 原始检测时间不改写，前台任务记录日志保持原样。
- 补充跨日、毫秒、时区覆盖、夏令时及无效时间边界测试。
- 延续 v1.1.2 的后台分类日志、设置交互与精简运行包，保留必要运行组件及许可，不包含本地配置和数据。

## 部署

镜像：`talktoo/iptv-studio:v1.1.3`，同步更新 `latest`，平台为 **linux/amd64**。

使用仓库的 Compose，执行 `docker compose pull` 后执行 `docker compose up -d`。升级前停止旧实例并备份数据目录，沿用原挂载；不要同时运行两个实例访问同一数据库。默认上海时区，无需另设 TZ。

在线 Demo 使用虚构数据；发布流程完成全部隔离回归及 Docker 镜像启动、日志、解码与重启持久化验证后发布。旧版 Release 和镜像标签均保留。
