# 频谱 IPTV Studio v1.1.8

本次版本回退了频道拖动排序，恢复频道库原有排序和交互；不会改变频道内部的线路择优、默认播放或订阅导出顺序。

## 台标优化记录

- 任务记录将“历史记录”替换为“台标优化”，集中查看台标处理的开始、等待检测、恢复、阶段进度和完成汇总。
- 台标优化部分完成时，可展开查看未能处理的频道及可读原因，例如地址不存在、限流、超时、连接失败或图片无法解码。
- 不展示台标真实地址或内部堆栈；静默缓存检查成功时不打扰，出现失败时仍会保留可追溯记录。

## 回退与精简

- 移除未达到交互预期的频道拖动排序入口、接口与排序持久化；保留既有频道整理、多线路管理、线路择优、试播、更新计划、节目单、统一输出、台标优化和智能分组能力。
- 发布包和镜像继续采用运行文件白名单，排除本地数据库、订阅、配置、缓存、日志、测试与开发材料；保留必要运行组件和许可证。

## 更新

版本镜像为 `talktoo/iptv-studio:v1.1.8`，同步 `latest`；旧版本镜像和 Release 保留。升级前备份整个数据目录，继续使用原有挂载与端口。

```sh
docker compose pull
docker compose up -d
```

在线 Demo 仅使用虚构数据，并随本次版本同步更新。

## 验证结果

候选镜像验证、完整隔离回归、运行包与镜像压缩对照结果将在发布时记录于此。
