# 代码清理与运行环境增量瘦身

本轮以清理开始时的完整本地代码为对照基线，包含当时尚未提交的台标订阅、台标优化、单源更新、错误透传和试播恢复修改。此前主线已经完成过一次镜像裁剪，本轮只统计额外减少的内容。

## 清理范围

- 删除没有前台入口的旧品牌、旧频道标题、旧播放质量和旧订阅状态行样式。保留组合选择器中的有效部分，以及通过动态列名生成的线路表样式。
- 删除仅供测试调用的 `canRecoverInSession` 包装函数，测试直接覆盖业务实际使用的 `recoveryDecision`。删除旧台标失败缓存的全局清空包装；只有隔离测试清理自身的模拟状态，不改变后台重试退避。
- 增量删除 Python 帮助主题数据、演示程序、在当前无 Tk 环境中无法使用的海龟图形入口，以及可能残留的编译链接产物。保留系统配置元数据、全部运行依赖、动态插件、证书、时区、解码器和许可。
- 未发现业务模块中可直接删除的第三方中间件，也未因“搜索不到直接导入”删除动态依赖。`cache_path` 等仍用于有效回归的辅助函数保留。

## 验证与发布约束

1. 本地隔离目录分别运行清理前后完整回归，不使用真实订阅或数据。
2. GitHub Actions 同机构建两版镜像，分别运行镜像启动、重启、解码、证书、时区、权限、持久化和完整隔离回归。
3. 比较频道状态、门槛边界、手动启停及订阅导出快照；固定媒体样本交替对比三种检测模式的判定、分辨率、解码、直播推进及异常分类。
4. 对保留的运行文件逐一比较摘要，仅允许删除上述明确的非运行内容；任何其他增删改均中止发布。
5. 验证成功后保存镜像及摘要；正式发布加载同一份已验证镜像，不重新构建。推送前核对当前运行源码和构建文件未变，拉取推送后的镜像再次检查。

运行包与镜像继续使用显式文件白名单；不包含数据库、直播订阅、凭证、`.env`、日志、台标缓存或测试媒体。对照脚本和构建报告不进入镜像。
