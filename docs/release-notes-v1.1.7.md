# 频谱 IPTV Studio v1.1.7

收紧默认自动启用条件：只有真正检测通过的线路才自动启用；“待复测”不再被当作通过结果。频道卡片、线路列表、首选播放及订阅输出使用同一启停判定。

## 检测与启停

- 默认开启“按检测结果自动启停”。未测、未通过、待复测及未能验证的线路不会默认启用或进入播放器订阅。
- 保留手动启停规则；同一任务内的异常复测保留首测决定的启停状态。关闭自动启停后仍沿用该设置的原有行为。
- 限流、网络拦截、超时仍属于未能验证，不当作废源；检测门槛、解码和直播推进要求不变。
- 保存新通过条件后，待线路重新检测才使用新规则。

## 精简与验证

- 复查已删除交接和研究文件的引用，未发现残留；没有引入运行依赖。
- 运行包和镜像继续按白名单构建，排除本地数据库、配置、凭证、订阅快照、日志及缓存，仅保留必要运行组件和许可。
- ZIP 使用高压缩；镜像独立构建默认 gzip 与 gzip9 对照，核对原始层摘要及运行配置，发布通过完整隔离回归的同一份产物。压缩收益不代表检测或播放提速。

## 更新

版本镜像为 `talktoo/iptv-studio:v1.1.7`，同步 `latest`，旧版本保留。当前验证平台为 linux/amd64，默认上海时区。升级前备份整个数据目录，继续使用原挂载和端口。

```sh
docker compose pull
docker compose up -d
```

在线 Demo 仅使用虚构数据，并与本次版本同步更新。

## 验证结果

- [候选镜像验证](https://github.com/Ringas/iptv-studio/actions/runs/44979477628)通过，镜像内 61 项隔离回归全部通过，启动、重启及数据持久化检查通过。
- 5 个原始层摘要及运行配置一致。相同源码的默认 gzip 为 88,308,398 字节，gzip9 为 88,107,135 字节，减少 201,263 字节（0.228%）。
- 运行包为 322,586 字节，仅含 27 个必要文件。相比上一版本镜像体积基本持平；没有为了体积删减运行、检测或解码能力。
- 旧版本保留，Demo 仅含虚构数据；发布产物不含本地数据与配置。
