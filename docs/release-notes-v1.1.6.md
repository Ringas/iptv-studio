# 频谱 IPTV Studio v1.1.6

恢复线路按钮的原有布局，统一胶囊开关交互，并将页面展示顺序与首选播放、订阅导出的标准排序分开。README 回归功能与使用指引，删除过时交接和研究材料。

## 界面与交互

- 线路列表、详情及批量操作栏恢复 v1.1.4 的按钮顺序、尺寸和样式，保留后续功能；桌面及手机窄屏保持相同规则。
- 胶囊开关仅允许操作本体，支持左右滑动和键盘操作；文字、空白及纵向滚动不触发切换。
- 鼠标悬停不改变状态文字颜色，解释仅在胶囊本体上显示；点击不显示外围选中框，保留键盘焦点提示。
- 沿用原保存规则，保存期间暂时禁用，完成后再允许切换；保存失败恢复原状态并提示。不保留试验性的并发切换、人工等待或乐观状态缓存。

## 排序与播放

- 当前页面更新状态、指标和数量，保留本次浏览的展示顺序；新项目追加，移除的项目不再显示。
- 重新进入页面、切换目录视图、重新打开对应弹窗或手动刷新时，按最新数据刷新展示顺序。
- 首选播放、首选速率与订阅导出继续使用最新启停和质量排序；显示位置不代表当前首选优先级，线路编号仍对应标准顺序。
- 不改变检测门槛、自动与手动启停规则，以及同任务异常复测规则。

## 文档与精简

- README 集中介绍频道整理、多线路管理、线路择优、网页试播、更新计划、节目单、统一输出、台标优化和智能分组。
- 补充镜像平台、网页解码和请求参数支持边界，以及管理台密码不保护订阅接口的必要说明。
- 删除旧开发交接和早期研究目录，移除引用；必要约束迁入 `docs/development.md`，详细用法迁入 `docs/usage.md`。历史内容仍可从 Git 历史取得。
- 合并重复开关样式、移除未使用字段和多余空行。镜像继续保留必要运行组件、证书、时区与许可，不为了体积删减解码能力。

## 部署与验证

版本镜像为 `talktoo/iptv-studio:v1.1.6`，并同步 `latest`；旧版本保留，平台为 linux/amd64。默认上海时区。升级前备份整个数据目录，沿用原挂载及端口。

```sh
docker compose pull
docker compose up -d
```

运行包按白名单打包并使用 ZIP 高压缩，镜像使用 gzip9。默认 gzip 与 gzip9 分别构建，逐层核对解压后摘要和运行配置；通过完整隔离回归后发布同一份镜像，并从仓库重新拉取复核。`COMPRESSION.json` 随 Release 提供，体积以实测为准，不将压缩收益解释为检测或播放提速。

在线 Demo 只含虚构数据。发布不包含本地数据库、订阅快照、配置、凭证、日志或台标缓存。
