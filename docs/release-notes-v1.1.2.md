# 频谱 IPTV Studio v1.1.2

本版完善后台日志可读性、检测设置生效时机与开关交互。旧 Release 和版本镜像全部保留，latest 更新为本版。

## 更新内容

- 后台及 Docker 日志按内容类型整行着色：进度蓝色、结果绿色、策略与耗时汇总黄色、诊断灰色。同类型不因成功或失败改变颜色；前台任务记录保持原样。
- 统一后台时间格式为 `2026-11-17 18:30:25.123`，不附加 `+08:00`。运行时默认上海时区，Compose 无需设置 TZ；仅在需要其他时区时覆盖。JSON 另含 timezone 字段且不含颜色控制符。
- 保存检测通过条件不重算已有检测结论，不立即改变线路启停、排序及导出；后续检测使用保存的新规则。只维护一套设置，不为每条线路新增生效规则。
- 设置页的“更新后检测”和“按检测结果自动启停”仅点击开关本身切换，文字及空白区域不再触发；键盘及辅助说明保留。
- 设置、线路、频道及订阅开关统一使用 160 毫秒滑动与变色节奏，兼容系统减少动态效果设置。
- 继续使用运行文件白名单生成发行包和镜像；排除本地数据、配置、日志、测试、研究材料及开发启动脚本，保留运行组件和许可文件。

## 部署与升级

镜像：`talktoo/iptv-studio:v1.1.2`，同步提供 `latest`，平台为 **linux/amd64**。

```yaml
services:
  iptv-studio:
    image: talktoo/iptv-studio:v1.1.2
    container_name: iptv-studio
    init: true
    ports:
      - "8787:8787"
    volumes:
      - ./data:/app/data
    restart: always
```

升级前停止旧实例并备份整个数据目录，继续挂载原有数据卷。执行 `docker compose pull` 和 `docker compose up -d` 后访问 `http://服务器IP:8787`。不要同时启动两个实例访问同一数据库。

运行 ZIP 包含固定版本 Compose、运行源码、构建文件和许可；SHA256SUMS 用于校验。在线 Demo 仅含虚构数据，不能用于真实线路检测或播放。

## 验证范围

发布流程先执行全部隔离回归，再验证镜像启动、上海默认时区、日志格式、订阅输出、播放资源、解码器、非 root 应用进程、重启数据保留及文件白名单，验证通过后发布。

检测验证标准保持不变；429、临时超时与网络拦截仍保留为未能验证。本次更新不宣称真实线路准确率或检测速度提升。
